# 05 — API Specification

The API is **spec-first**: `api/openapi/openapi.yaml` (OpenAPI 3.1) is authored by hand per this document; server interfaces (`oapi-codegen`) and the TS client types (`openapi-typescript`) are generated from it. This doc defines conventions and the complete endpoint surface; write the YAML to match.

## Conventions

- Base path: **`/api/v0`**. Versioned path, unstable until Phase 3 declares v1.
- JSON everywhere; requests `application/json` except attachment upload (`multipart/form-data`).
- Timestamps RFC 3339 UTC (`2026-09-12T09:00:00Z`). IDs are UUID strings.
- Authentication: session cookie `osctf_session` (see [`06-auth.md`](06-auth.md)). No tokens/keys in v0.1.
- CSRF: mutating requests (POST/PATCH/DELETE) must carry an `Origin` (or `Referer`) header matching `OSCTF_BASE_URL` — enforced by middleware; cookie is `SameSite=Lax`. Non-browser clients (curl, agents) simply set `Origin` or use GETs.
- **Errors: RFC 9457 problem+json**, content type `application/problem+json`:

```json
{
  "type": "https://osctf.dev/errors/validation",
  "title": "Validation failed",
  "status": 422,
  "detail": "One or more fields are invalid.",
  "errors": { "username": ["must be between 3 and 32 characters"] }
}
```

Error catalog (the `type` suffix after `/errors/`):

| status | type | when |
|---|---|---|
| 400 | `bad-request` | malformed JSON, schema violation |
| 401 | `unauthenticated` | no/invalid session |
| 403 | `forbidden` | authenticated but not allowed (role, banned, max attempts, event not running) |
| 404 | `not-found` | missing or invisible resource (invisible challenges are 404, not 403 — don't leak existence) |
| 409 | `conflict` | duplicate username/team name, already solved, team full, already on a team |
| 422 | `validation` | field-level failures (with `errors` map) |
| 429 | `rate-limited` | over limit; includes `Retry-After` header (seconds) |
| 500 | `internal` | generic; detail only in server logs (correlate via `request_id` extension member) |

- Pagination (admin list endpoints): `?page=1&per_page=50` (max 200); response envelope `{"items":[...], "total": 1234, "page":1, "per_page":50}`. Participant-facing lists (challenges, scoreboard) are unpaginated in v0.1 — event scale doesn't need it.
- Every response carries `X-Request-Id` (generated by middleware, logged).

## Endpoint reference

Auth column: `public` (no session) · `user` (session) · `team` (session + team member) · `admin`. All paths below are under `/api/v0`.

### Auth & account

| Method & path | Auth | Description |
|---|---|---|
| `POST /auth/register` | public | `{username, email, password}` → creates user, starts session. 409 on duplicate. Disabled when `OSCTF_REGISTRATION_OPEN=false` (403). |
| `POST /auth/login` | public | `{email, password}` → session. Generic 401 on any failure. Rate-limited. |
| `POST /auth/logout` | user | Destroys session. 204. |
| `GET /auth/me` | user | Current user: `{id, username, email, role, team: {id, name, role} \| null}` |
| `PATCH /auth/me/password` | user | `{current_password, new_password}` → 204; revokes all *other* sessions of the user. |

### Users (public profiles)

| Method & path | Auth | Description |
|---|---|---|
| `GET /users/{id}` | public | `{id, username, team: {id,name} \| null, solves: [{challenge_id, slug, title, category, points, solved_at}]}`. Hidden users 404 to non-admins. |

### Teams

| Method & path | Auth | Description |
|---|---|---|
| `POST /teams` | user | `{name}` → creates team, caller becomes captain + member. 409 if already on a team or name taken. Returns team incl. `invite_code`. |
| `POST /teams/join` | user | `{invite_code}` → joins. 409 if on a team / team full / team banned. |
| `POST /teams/leave` | team | Leaves; captaincy transfer per [`04-database.md`](04-database.md). 204. |
| `GET /teams` | public | Non-hidden teams: `[{id, name, member_count, rank, points}]` |
| `GET /teams/{id}` | public | `{id, name, members: [{id, username}], rank, points, solves: [...]}` (as user solves shape, plus solver username). `invite_code` **only** when the caller is a member. |
| `PATCH /teams/{id}` | team (captain) | `{name?}` rename. 409 on duplicate. |
| `POST /teams/{id}/invite-code` | team (captain) | Regenerates invite code → `{invite_code}`. |

### Event & challenges (participant-facing)

| Method & path | Auth | Description |
|---|---|---|
| `GET /event` | public | `{name, description, starts_at, ends_at, frozen: bool, phase: "pre"\|"running"\|"ended"}`. `freeze_at` value itself is admin-only. |
| `GET /challenges` | user | Visible challenges, only when phase ≠ `pre` (else 403 `event-not-started` detail). Each: `{id, slug, title, category, difficulty, points (current value), solves (count), solved_by_me (team), kind, has_instance, connection_info \| null}`. **Never** description/flag fields in the list. |
| `GET /challenges/{slug}` | user | Full public detail: adds `description`, `attachments: [{id, filename, size_bytes}]`, `max_attempts`, `attempts_used`, `connection_info` (rendered template, e.g. `nc ctf.example.com 30017`, null unless instance running). |
| `GET /challenges/{slug}/attachments/{id}` | user | Streams the file (`Content-Disposition: attachment`). Same visibility rules as the challenge. |
| `POST /challenges/{slug}/submit` | team | `{flag}` → `{correct: bool, points: int \| null}`. Guards: phase = `running`, not already solved (409), attempts left (403), rate limits (429). Always logs the attempt. |
| `GET /scoreboard` | public | `{frozen: bool, generated_at, standings: [{rank, team_id, name, points, last_solve_at, solves: int, banned: bool}]}` — full snapshot, hidden teams excluded. |

### WebSocket

`GET /api/v0/ws` (upgrades; public). Server → client messages, JSON, `{"type": ..., "data": ...}`:

| type | data | sent when |
|---|---|---|
| `hello` | `{frozen: bool}` | on connect |
| `scoreboard` | full scoreboard payload (as REST) | on connect, and on every standings change (throttled to ≥ 1 s between broadcasts, latest wins) |
| `event.phase` | `{phase}` | when the event transitions pre→running→ended (checked by the freeze/phase ticker) |

No client→server messages (ignore any). Ping/pong per protocol every 30 s; drop dead connections. During freeze, broadcasts simply stop for non-admin consumers — there is no per-connection auth in v0.1, so the hub broadcasts the *frozen* snapshot to everyone and admins rely on REST for live data. Frontend behavior in [`09-frontend.md`](09-frontend.md).

### Admin — event, challenges, instances

All `admin` auth. Every mutation writes an `audit_log` row.

| Method & path | Description |
|---|---|
| `GET /admin/event` / `PATCH /admin/event` | Full event incl. `freeze_at`. PATCH validates window constraints. |
| `GET /admin/challenges` | All challenges (incl. invisible), paginated, `?category=&visible=&kind=` filters. Includes flags. |
| `POST /admin/challenges` | Create. Full field set per [`04-database.md`](04-database.md). Slug auto-derived from title if omitted. |
| `GET /admin/challenges/{id}` | Full detail incl. flag, container config, instance summary. |
| `PATCH /admin/challenges/{id}` | Partial update. Changing `flag` or scoring fields triggers scoreboard recompute. |
| `DELETE /admin/challenges/{id}` | Refuses (409) if visible during running event unless `?confirm=true`. Destroys instance first. |
| `POST /admin/challenges/{id}/attachments` | multipart upload (field `file`), ≤ `OSCTF_MAX_ATTACHMENT_MB`. 409 on duplicate filename. |
| `DELETE /admin/challenges/{id}/attachments/{aid}` | Removes from store + DB. |
| `POST /admin/challenges/{id}/instance` | Deploy (sync, ≤ 120 s). → instance object. |
| `GET /admin/challenges/{id}/instance` | `{id, state, host_port, started_at, last_health_at, error, connection_info}` |
| `POST /admin/challenges/{id}/instance/restart` | Stop + start same container. |
| `DELETE /admin/challenges/{id}/instance` | Destroy container, free port. |
| `GET /admin/challenges/{id}/instance/logs?tail=200` | `{logs: string}` (max tail 1000). |

### Admin — users, teams, submissions, stats

| Method & path | Description |
|---|---|
| `GET /admin/users` | Paginated, `?q=` search on username/email, `?banned=&hidden=&role=` filters. |
| `PATCH /admin/users/{id}` | `{banned?, hidden?, role?}`. Banning revokes sessions. Cannot un-admin or ban yourself (409). |
| `POST /admin/users/{id}/password` | `{new_password}` — the v0.1 reset path. Revokes the user's sessions. |
| `GET /admin/teams` | Paginated, `?q=` search. |
| `PATCH /admin/teams/{id}` | `{banned?, hidden?}`. |
| `GET /admin/submissions` | Paginated, filters `?challenge_id=&team_id=&user_id=&correct=&since=&until=`. Rows include `provided`, `ip`. |
| `GET /admin/stats` | `{users, teams, submissions, solves, instances_running, ws_connections}` — the admin dashboard tiles. |

### Operational (not under /api/v0)

| Path | Auth | Description |
|---|---|---|
| `GET /healthz` | public | 200 if process is up. |
| `GET /readyz` | public | 200 when PG, Redis, MinIO reachable; else 503 with failing component names. |
| `GET /metrics` | public (compose-internal) | Prometheus. Operators must not expose it through their proxy — note in docs. |
| `GET /*` | public | Embedded SPA: exact-match static files, else `index.html` (client routing). `/api/*` never falls through to the SPA. |

## OpenAPI authoring rules

- `operationId` = camelCase verb+noun (`submitFlag`, `listChallenges`, `deployInstance`) — these become generated method names.
- Schemas under `components/schemas` named `PascalCase` (`Challenge`, `ChallengeAdmin`, `ScoreboardEntry`, `Problem`). Participant and admin representations are **separate schemas** — never one schema with "sometimes present" sensitive fields (`flag` must be structurally absent from participant types).
- Every endpoint documents its error statuses with the `Problem` schema.
- Lint with `vacuum` in CI; zero warnings policy.
